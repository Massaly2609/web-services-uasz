# Consignes des exposés

## Points à traiter dans chaque exposé

- Introduction du web service
- Fonctionnement (format d’échange des données, exemples de requêtes / réponses…)
- Spécification ou langage de définition (IDL) : WSDL, OpenAPI, SDL, Protobuf…
- Avantages et inconvénients
- Sécurité
- Tableau comparatif avec les autres web services

## Travail demandé après chaque exposé

1. Créer un serveur avec la technologie de son choix (Java, Python, PHP…).
2. Créer une classe `Personne` avec les méthodes **Ajouter, Lister, Rechercher, Modifier, Supprimer**.
3. Mettre en place le service web selon l’exposé.
4. Tester les services avec **Postman**.
5. Créer un **client dans une technologie différente du serveur** qui accède aux méthodes exposées.

Chaque étudiant doit faire ce travail pour l’exposé de chaque groupe, y compris celui du professeur
(XML-RPC et JSON-RPC).
